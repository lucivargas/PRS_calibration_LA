## PRS_calibration_LA

# Introduction

`PRS_calibration_LA` implements a method to calibrate polygenic risk scores (PRS) using local ancestry. 

# Dependencies

The following GNU packages are required:
 bcftools
 plink2
 R
 yq
 parallel

The following R packages are required
tidyverse
 argparse
 stringr
 doParallel
 foreach
 boot
