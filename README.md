## PRS_calibration_LA

# Introduction

`PRS_calibration_LA` implements a method to calibrate polygenic risk scores (PRS) using local ancestry. 

# Dependencies

The following GNU packages are required:<br>
 - bcftools<br>
 - plink2<br>
 - R<br>
 - yq<br>
 - parallel<br>

The following R packages are required: <br>
 - tidyverse<br>
 - dplyr<br>
 - argparse<br>
 - stringr<br>
 - doParallel<br>
 - foreach<br>
 - boot<br>
